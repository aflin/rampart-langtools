# test_docs — OCR test fixtures

Sample pages for the `rampart-ocr` test suite (see
`claude-work/rapidocr-plan.md`). Every file here is either generated by
this project or in the public domain, so the directory may be
redistributed with rampart-langtools without restriction — the same
footing as `test_images/` (CLIP) beside it.

| file | KB | what it exercises |

## Ground truth

### Synthetic pages — exact

`synthetic-memo.png` / `.pdf` / `synthetic-scan.pdf` and the rotated
variant all carry the same text, generated from `mk/memo.ps`, so
assertions can be exact:

    RAMPART LANGTOOLS TEST DOCUMENT
    This page was generated for the rampart-ocr test suite.
    It contains no third party content and is public domain.
    Detection and recognition:
    The quick brown fox jumps over the lazy dog.
    Pack my box with five dozen liquor jugs.
    Numerals: 0123456789   Symbols: $ % & @ # -
    Fixed width line: ABCDEFGHIJKLMNOPQRSTUVWXYZ
    Invoice 4471-B     Amount 1,250.00 USD
    Page 1 of 1                        RAMPART-OCR-000001

Two pangrams cover the lowercase alphabet, the Courier lines cover a
fixed-width face, and `RAMPART-OCR-000001` is a Bates-style stamp in the
footer — the discovery-corpus shape the plan is aimed at, and a good
check that a small, isolated, far-from-everything-else line is still
detected.

### `nasa-tn-d1766-p2.jpg` — hand-checked lines

The source PDF *does* carry a text layer, but it is a poor legacy OCR job
(`ADMINISTMTION` for `ADMINISTRATION`, `v e r t i c a l` for `vertical`,
`I N` for `IN`), so **do not use it as ground truth** — it is a useful
baseline to beat, not a reference. These lines were read off the image
by hand and are unambiguous:

    NATIONAL AERONAUTICS AND SPACE ADMINISTRATION
    TECHNICAL NOTE D-1766
    WIND-TUNNEL TESTS OF TWO VTOL
    PROPELLERS IN DESCENT
    By Paul F. Yaggy and Kenneth W. Mort
    SUMMARY
    INTRODUCTION

### `nytimes-1918-p1-top.jpg` — hand-checked lines

    The New York Times          (blackletter masthead — the hard one)
    ARMISTICE SIGNED, END OF THE WAR!
    BERLIN SEIZED BY REVOLUTIONISTS;
    NEW CHANCELLOR BEGS FOR ORDER;
    OUSTED KAISER FLEES TO HOLLAND
    "All the News That's Fit to Print."
    NEW YORK, MONDAY, NOVEMBER 11, 1918.

Suggested assertion style: require the ALL-CAPS display headlines (which
any working OCR must get) and treat the blackletter masthead and the
small body type as reported-but-not-asserted, so the test measures
regressions rather than encoding one engine's exact output.

## Notes

- Sizes are deliberately modest. The newspaper is a crop rather than the
  full broadsheet: cropping preserves the source resolution that small
  newsprint type needs, where downscaling the whole page destroyed
  legibility and — because halftone noise is expensive to encode —
  actually produced a *larger* file.
- `mk/` holds the generators, kept so the synthetic fixtures are
  reproducible and their provenance is self-evident.
- No model files live here; OCR models resolve through rampart-models by
  catalog alias.
